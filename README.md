## Currículo Online - Camila H. Siqueira
Este repositório contém o código-fonte do meu **site de currículo profissional**, desenvolvido com o objetivo de apresentar minha experiência técnica em **Infraestrutura de TI, Administração de Sistemas, Banco de Dados, Cloud e Automação**.
Embora minha atuação principal seja na área de infraestrutura, este projeto também representa minha evolução no desenvolvimento web, unindo **estrutura, clareza técnica e foco em valor de negócio**.

### 🎯 Objetivo do Projeto
- Centralizar meu currículo em um formato **moderno, acessível e navegável**
- Demonstrar experiência prática em **ambientes críticos e corporativos**
- Aplicar conceitos de **organização, padronização e automação**, comuns à Infraestrutura, no desenvolvimento do site
- Servir como base para evolução futura (cases, serviços e automações)

### 👩🏻 Sobre mim
Sou **Analista de Infraestrutura**, com sólida experiência em:
- Ambientes Windows e Linux
- Virtualização e Datacenter
- Microsoft 365, Entra ID, Intune e Segurança
- Banco de Dados (Oracle, SQL Server, PostgreSQL, MySQL e MongoDB)
- Automação com PowerShell, Shell Script, Power Automate e Ansible
- Monitoramento e observabilidade
<div>
Atuo com foco em estabilidade, segurança, continuidade operacional e redução de riscos, conectando decisões técnicas às necessidades do negócio.
</div>
